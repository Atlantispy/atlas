## Mechanism and source boundary

The shell change retains an already funded immutable intermediate from the
original inner clipping path when the lower radial boundary is satisfied. All
original clipping, volume, witness and contact proofs finish first. An additional
funded exact-volume calculation may then strengthen the lower bound, with the
existing outer bound checked. Extra-work refusal propagates; it does not fall
back to the earlier result. An identity-no-op lower clip is left alone.

The quadrature change preserves every successful preferred-axis choice. Only
when that choice declines does it fund a bounded search of the remaining
admissible axes. The existing containment condition must hold for an alternative;
otherwise it still declines. Function signatures and imports are unchanged.

These are stronger endpoint certificates, with explicit costs. They are not
bit-identical records or all-budget refusal parity. The retained source and
resource contracts remain in force; no tolerance or scientific acceptance gate
is relaxed. No new research or numerical run was performed for publication.
