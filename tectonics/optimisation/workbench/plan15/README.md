## Sweep acceptance and admission contract

The genuine W4 same-call control remains the 236-cell/832-face g13l1 fixture;
this worker-count experiment adds no solver or partition/halo algorithm. Run one
fresh process per authentic 6,8,10,12,8,6 arm. It has no single-worker baseline.

Both legacy and compact results must have nonempty matching array-identity maps
and matching result_id, metadata_sha256 and metadata_bytes. Missing/None identity
cannot pass. Worker-only changes allow no invented numerical tolerance or identity
translation. Require every arm and total_calls==len(calls), because the helper
retains only its latest calls; truncated history is incomplete. Preserve source/
layout/reference identities before and after, and use new exclusive outputs.

For each call, expected workers are min(requested,to_reconstruct) only when the
minimum-face threshold is met and at least two workers are useful, otherwise 0.
Legitimate serial small calls pass. Every expected parallel call must use its
expected count without fallback; active metering and ledger cuts still apply.

| Result | Exit | Interpretation |
| --- | ---: | --- |
| PASS | 0 | All requested arms/fields/calls, exact parity, configuration and workers complete |
| FAIL | 1 | Missing/stopped/failed/incomplete/nonidentical evidence, wrong reporting or changed inputs |
| WORKERS_REDUCED | 3 | Arrays identical but a required count reduced/fell back; invalid requested-count timing |

Child exit 0 alone is insufficient; failure/reduction grants no automatic repeat.
The efficiency ratio worker_compute_seconds/(used_workers*call_seconds) is
diagnostic, not T(1) scaling, a 60% threshold, a four-worker clamp or a guarantee of
speedup. Preserve per-call reconstruction and legacy/compact/end-to-end timings,
expected/actual workers, fallbacks, worker/tree peaks, machine load and hook state;
overlapping phases are not additive.

Per-arm admission uses an explicit matching route/worker/input/source/mode key and
successful completed evidence. The adapter, not start_gate core, validates that
evidence; failed/incomplete or parent-only/different-worker records cannot lower
the TOTAL prediction. Use the largest qualifying peak, else grounded ticket
prediction/booking with provenance, then exact integer P+ceil(P/5)+2*2**30.
A 4-GiB booking gives7,301,444,404 bytes, not a float-truncated approximation.
Record the complete core decision, basis, gate and available memory, not a
hand-built two-field object. Initial refusal precedes sweep-output creation;
later refusal retains completed arms and explicit failure evidence.

Runtime imports use clean seed 0 environment and single-thread numerical libraries,
without -I/-E. Queue capacity must account for parent and actual worker policy,
not infer half-core units from a stale booking. Admission does not raise12-GiB
tree RSS/1-GiB floor/16-GiB logical or 256-MiB scope/1-MiB integer/256-step limits.
Time escalation follows the actual authorised booking, not an invented kill timer.
