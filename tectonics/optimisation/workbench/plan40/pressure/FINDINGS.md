WORKING NON-CANON. The selected numerical sources have completed code review and controlled component measurement. The selected I2 receiving combination is **core G1/G2/G3/G7/G10 plus G4**. ## Decision and measured scope

The largest useful changes remove discarded midpoint derivatives and repeated complete profile/donor calculations. The exact full-interval jets still supply curvature bounds. The receiving core also shares radial power prefixes, removes literal duplicate vector work and reuses identical polygon wedges within one partition. G4 adds exact repeated-operand products and guarded rational negation to the remaining full-jet arithmetic.

The actual receiving comparison (q81) preserves complete exact outputs and leaf counts across four fixed synthetic full-call fixtures. Core saves **27.35–61.94%** against the original. Adding G4 saves another **0.189–1.022%** by marginal medians across all four; two sample ranges are separated. G5 has positive marginal medians but overlap in all four, and G4+G5 has mixed marginal signs, so G5 remains unselected and inconclusive. An individual path regression is not a veto; selection concerns the measured net effect of the added change, without invented production weights.

See [MEASURED-RESULTS.json](MEASURED-RESULTS.json) for selected public-safe q77/q81 result fields and their exact sample/source identities, and [implementation/README.md](implementation/README.md) for the actual source selection and qualification. The original q81 result SHA-256 is `1fb344bfac49061ed0627ec69499652bd2d790b0ac5e11c953b1b7d358cf3dd8`; the public selected-field copy is a separately identified publication, not the original report or a rerun.

The four full-call fixtures are duplicate, distinct, mixed-support and bulk mixed-support (32 profile + 32 donor rows). They include fresh real budgets, ownership, optional admissions, cleanup and full fallback costs. The bulk fixture reaches G1's cumulative 256 KiB scratch cap and falls back to full jets; its result remains exact. The finite declared width deliberately avoids adaptive subdivision. These are complete component calls, not a measured pressure stage, representative production distribution, large-IV throughput, or whole-IV saving. No percentages are summed or frequency-weighted into such a claim. No material RAM saving or cross-platform execution is established.

## Actual receiving resource and exactness contract

The selected wall worker issues a private, active, thread-bound custody token only around serial computation after creating its fresh root ledger. Structural root checks alone do not prove private ownership for arbitrary library callers. Missing, scoped, revoked, parented or otherwise ineligible ownership cleanly declines optional reuse. Original mandatory admissions precede optional work and retain their ordering, cancellation and refusal behaviour.

G1 uses a separate optional 256 KiB reservation and cumulative retained-size accounting for bounded value/tag objects, with no derivative DAG. Unknown constancy and capacity misses clear payloads and release the lease before full fallback. Arithmetic errors and cancellation propagate after cleanup; they are not optimisation misses. Registration precedes attaching payload so an append failure cannot strand an unregistered wrapper's payload. Original precision context, radial expression witnesses, shortcut/identity decisions, outward rounding, error bounds and leaf/refinement order remain.

G2 has two eight-entry namespaces sharing one 64 KiB optional reservation, including conservative object and rational-payload accounting. Keys are `(bottom,top,rho,ptop)` for profiles and `(entry,exit,bottom,top)` for donors. Only completed results are retained; every original row still scales, adds and updates flags in order. G10 holds at most eight completed wedge results within its 64 KiB optional partition reservation. Unsupported representations/cap misses compute normally. Cache/lease cleanup applies on success, error, cancellation and retained tracebacks. G10 expires before angular integration; G2 expires before callback return; G1's candidate lease is gone before G2-capable full fallback, so these optional epochs do not overlap.

Focused actual receiving evidence includes real-budget optional shortfall, mandatory-admission preservation, complete exact outputs, capacity misses and exception/traceback cleanup. Separate strict full-module import evidence binds the actual source closure; source-extracted measurement calls do not replace that import proof. No tolerance, precision policy, quadrature, physical EOS, projection, coefficient coalescing, native boundary or selected source-map membership is changed by this examination package.
