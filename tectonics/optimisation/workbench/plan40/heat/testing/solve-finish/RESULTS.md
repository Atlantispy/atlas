## Resource and failure interpretation

Original numeric refusals, source checks, core safe points and ordering remain covered where stated. Synthetic slots/owners deliberately expose ownership and fault boundaries without calling themselves native admission. C9 additionally keeps the omitted addition's original admission with its original operands; changing either original operand invalidates reuse. It keeps original boundary-debited and source-only arrays distinct. Its optional cache must be disabled when that independent storage is not already funded.

C10 stores only the latest feasible interior exact state and certificate. It copies references into a separate bounded cache before the source attempt arrays are dropped; replacement includes old/new overlap. The illustrative six-slot count covers two energy and one face entries across replacement, **not** proof dictionaries, native numbers, container overhead or a complete resource bound. The prototype's exact quadratic predicate is deliberately injected, so its retained proof is not the production proof graph. This is the precise remaining native-owner seam, not evidence that runtime integration has passed.

C7's test guard detects invalidated factor/pivot/entry identity and expires on owner close. The benchmark exercises local private factor construction plus view construction and three solves; it does not suggest a global cache for caller-mutable dictionaries. C19's optional cache never avoids the original mapping read. An unsupported type or missing optional capacity uses the original conversion.

No native allocation counts, RSS limit, performance saving or full-heat applicability frequency was measured. The direct tests use one process, native thread environment limits of one, fixed matrices with at most three rows, a two-cell finish state and bounded 64-step searches. Below 1 GiB and a few minutes are conservative **projected** bounds, not measurement results.

Selected-source traceback locals can still belong to an escaping exception; this repair establishes retirement of the extra cache-owned state, not native traceback/resource qualification.
