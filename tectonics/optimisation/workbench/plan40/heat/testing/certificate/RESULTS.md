## Ownership and resource findings

exception or only its traceback is held. C5 retains 192,512 accounted bytes in
the equivalent test. Both release to zero after all failed-frame custody drops.
The failed intermediate test caught this precise defect; the corrected owner
retains `_preserve_workspace`'s returned object on the owner also held by the
failed source frame.

C11 retains one precision only, funds old and new caches simultaneously before
replacement, and never stores an exception or traceback. Per-dot first-flag
transition metadata preserves sticky flags at the original prefix cancellation
positions, not only at the final answer. A complete-reference fallback is used
when initial retention cannot be funded; failed replacement admission preserves
the already-funded old prefix. The rank-20 smoke holds the promised 800 Gram
endpoints plus explicitly charged metadata; complete two-attempt peak accounted
bytes are 22,836,642 baseline and 49,774,080 candidate. Those conservative ledger
figures are not measured resident-memory increases. The no-funding candidate has
the same 22,836,642-byte peak as its reference and still returns the same result.

C16 keeps the full existing interval plan. Its retained converted matrix replaces
the later physical conversion inside the already-overcharged scalar/container
generations. The fixed owner holds aliases and context metadata; every physical
coordinate retains its original check. The owner drops before normal refusal
close or successful export shrink; an unexpected failed frame remains covered by
the original attempt workspace. Entry admission can refuse before the owner has
captured any matrix.

Observed final correctness process peak working set: 154,558,464 bytes
(about 147.4 MiB). This includes native import/JIT; it is not a production memory
bound. One available CPU is selected for the child process. Final correctness

a new output path and an explicit checkout containing the unchanged selected map.

Optional repeated `--candidate C3` etc. restricts the exact candidate set. The
complete set is C3, C4, C5, C11, C15, C16, C17. No code rewrite is needed when this
same file is copied beneath the public heat testing directory.

Prepared benchmark inputs are synthetic identity observations of ranks 4 and 20,
320-bit contexts and exact dyadic RHS; they are not asserted to match production
rank/zero-frequency distributions. Each candidate is independent. Four
counterbalanced baseline/candidate pairs execute four complete calls per arm at

prefix mismatch and unavailable optional funding. Its timed unit includes an
actual r3 normal-refusal attempt followed by a complete accepted attempt.

release. C3/C4/C5/C15/C17 measure complete solve-plus-physical components under the
unchanged interval reservation. C16 measures the actual full r3 attempt. Baseline
native import/JIT/self-test and C3's successor import/JIT/self-test are separately
reported. Comparison signature capture is inside component calls and adds harness
overhead equally; report it when interpreting timings. No overlapping candidate
savings or whole-heat projection may be formed.

Correctness mode executes those exact benchmark component closures once per arm
and scenario, including rank 20, without a comparison timing loop or reporting
