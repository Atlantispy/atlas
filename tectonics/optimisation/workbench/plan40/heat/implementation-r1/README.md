## C13 polygon experiment: not adopted

The actual native-owner/source-check comparison was **6.001% slower**, so C13 is
retained as an unselected experiment. Its earlier six-sample component median
4.53525 → 4.47070 ms (1.42%) was modest, overlapping and not a production saving.
C1/C2/C12/C14 cache prototypes also regressed; their results do not justify this
receiver. The original dispositions/accepted measurement identities remain in
functional/MEASURED-DISPOSITION.json and the [actual measurements](MEASUREMENTS.md).

The three additive functional modules are polygon_numerics_40b_r1 (normal-square,
edge and immutable symmetric-value reuse), polygon_moment_40b_r1 (actual M.admit,
full prospective plan, original shrink and counted-retention r4 transfer) and
functionals_kernel_40b_r1 (selected r5 body with only MOMENT import changed).
SOURCE-GENERATION owns their complete file identities; no live forward/issuer
was silently retargeted.

Original M1 inventory charges all generated exact scalars cumulatively. Retained
normal/edge values were already generated within that charge, and copied symmetric
values satisfy both original output-slot bounds. Keep three independent row lists,
nine references, original full scalar-operation/max-expression plan and fixed
`80*N+128` container allowance. Retained-value r4 counts aliases repeatedly; no
cache/extra container or reduced admission is introduced. The prototype's 65 KiB
extra lease is not transplanted. Source reads are bounded to 64 KiB, one helper
at a time inside existing source buffers, after metadata admission and before the
original full-plan reservation; changed bytes or numerical callable refuse.

Four shapes/thirteen fault controls preserve values, full plan, polls and peak
accounting, including geometry/cancellation/one-byte-short/source/callable/transfer
failures. Actual M1/M4 factories, WorkBudget, retained r4, functional binding and
prescribed-power face consumer execute. Escaping errors retain native leases until
traceback custody drops; borrowing after close refuses. Geometry START uses explicit
component source-fence injection; import-only bounds/parallel shells do not qualify
workers or complete non-power reconstruction. Production code retains real fences.
