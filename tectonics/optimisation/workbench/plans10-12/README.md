## Producer-only initial-measurement trust contract

Reuse applies once per starting lineage to the 969 initial component
measurements. Interval2+ restores the sealed spatial owner without initial_metrics;
the independent reader still recomputes. It is not a generic planetary-table cache.

1. **Recorded closed source.** Record initial-measurements.sqlite only after
   admission closes, in the root receipt with composition/counts and seed. The
   launcher passes that receipt's recorded store pin, never manufactures a pin
   by hashing whichever file is present at launch.
2. **Authenticated lineage/composition.** Require the adopted root with successful
   runner/reader/finalise/adopt, exact receipt/verdict/adoption sequence, matching
   producer PID/workflow/profile and named measurement store. Compare the full
   union of composition keys: profile, source proof, advance driver, all helpers
   and interpreter seed. A parameter hash, cache key or historical fixture digest
   cannot authenticate another world or composition.
3. **Producer-only copy.** Seed outside shared FRESH.admission; default is no seed.
   The reader refuses --seed arguments, ATLAS_INITIAL_MEASUREMENT_SEED and any
   existing store/-wal/-journal/-shm before admission. The producer also refuses
   that ambient variable: source input must be explicit. Changed drivers need
   explicit successor profile/source/advance-driver/receipt identities.
4. **Exclusive verified copy.** Require ordinary closed source, no source sidecars,
   absent destination/sidecars and correct recorded pin. Hash before copy, create
   exclusively, hash the copied stream, flush/fsync, check stream hash, rehash both
   files and recheck source sidecars. Failure records REFUSED_BEFORE_ADMISSION and
   re-raises; invalid seeds never fall back to fresh generation. Tampering belongs
   only in disposable fixtures, never the golden source.
5. **Honest outcomes.** Record reuse source, store/receipt/verdict/adoption pins,
   copy details and hit/miss counts. FULL_REUSE requires zero misses and unchanged
   bytes. MISSES_MEASURED is a valid-seed milestone, not invalid-seed fallback.
   COUNTS_DISAGREE_WITH_BYTES remains an inconsistency, not successful reuse.
6. **Fail-closed proof.** Required fields must exist and pass: bounds_id,
   geometry_id, workflow_id, store_unchanged_from_seed, empty sidecars, both
   store pins and the recorded Run-A workflow/bounds identities. Missing/false
   required fields produce nonzero failure. Earlier always-zero proof/missing
   plumbing findings were repaired, not evidence of a current defect or complete
   final-generation coverage.
7. **Focused actual runner coverage.** Retain wrong-pin/sidecar/existing-target/
   missing-path/profile/seed/refused-reader evidence and bounded before-advance
   Run-B smoke through the real runner. Reuse valid checks; changed seams require
   only their necessary authorised controls, not another scientific interval.
8. **Limited meaning of a hit.** It checks stored-field/request consistency, not
   fresh geometric certification. ROOT_IDENTITY and the independent reader's full
   recomputation remain separate backstops.
